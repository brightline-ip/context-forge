Output and model

Output contract

normalized.md
Clean source text with page, slide, sheet, and section locators.

chunks.jsonl
Stable, hashed chunks ready for a frontier model or vector store.

context-capsule.*
Optional bounded Qwen summary; failure never fails extraction.

manifest.json
Source hash, warnings, provenance, and processing status.
